# Configuration UI verification

Seven browser assertions passed using the actual reusable package form and
catalog rows in a deterministic local host fixture. `annotations.json` records
assertions and capture times. The PNG files show each resulting page.
`annotated-steps.mp4` is a time-compressed screenshot step recording with selectable
assertion subtitles. It is not continuous screen video.

The fixture verifies exact pay-as-you-go rates, invalid and valid included units,
manual prepaid package policy, sanitized provider errors, immutable managed meter
selection and account/seller state reset. These fixtures make no provider calls,
create no payments or grants, and do not establish financial acceptance. The
runnable example and native financial verification are separate work.

Serve the repository with Vite and open
`/scripts/fixtures/usage-configuration-ui.html` to repeat the local UI checks.
