## Why this matters

Four small, independent frictions, bundled because each is under 30 minutes:
(a) the example README tells users to copy `.env.local.example`, which does
not exist — the very first setup step fails; (b) `shadcn` is a runtime
dependency of the example but is never imported (it's a CLI/config tool), and
it is also the sole source of the repo's one `pnpm audit` advisory
(brace-expansion, moderate, via `shadcn > ts-morph > @ts-morph/common > minimatch`);
(c) the main README omits two real public methods (`closeAccount`,
`getV2Account`), so users can't discover them without reading source; (d) the
repo has no `CLAUDE.md`, so every agent session re-derives build commands and
branch strategy from scratch — including the executors of these plans.
